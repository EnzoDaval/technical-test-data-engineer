## _Utilisation de la solution (étape 1 à 3)_

_Inscrire la documentation technique_
Exécuter "docker build -t fastapi" pour construire l'image Docker, puis, exécuter "docker run -p 8000:8000 fastapi" pour lancer le container qui exécutera l'API.

Exécuter "python script.py" pour démarrer le pipeline de données, qui s'executera une fois par jour. Le contenu de la base de données SQLite est print sur le terminale à chaque exécution du pipeline.

Pour lancer les tests, exécuter "python -m pytest test/" (pytest à la racine du projet ne fonctionnait pas pour moi).
